# 📖 Overview

The **Startup Funding Tracker** is a modern web application that allows users to explore startup funding data with powerful filters, real-time search, and interactive dashboards.

It provides insights into:
- Funding trends over time
- Industry-wise investments
- Recently funded startups
- Category-based analysis (AI, Fintech, etc.)
# ❗ Problem Statement

Accessing startup funding data is often:
- Scattered across multiple platforms
- Not easily filterable
- Lacking visualization

Users (students, analysts, investors) need a **centralized and interactive platform** to analyze funding trends efficiently.

# 💡 Solution

This project solves the problem by:
- Fetching real-time funding data via API
- Structuring it into meaningful insights
- Displaying it using interactive charts and dashboards
- Providing filters for better analysis

# 🏗️ Architecture

The application follows a **modern component-based architecture**:


User → UI → API Layer → Data Processing → Visualization


- UI handles interaction
- API layer fetches data
- Data is processed and structured
- Charts display insights

---

# 🔄 Data Flow

1. User selects filters/search
2. Request sent to API
3. Data fetched from Firecrawl
4. Data processed and cleaned
5. UI updates dynamically

```bash

3. Setup Environment Variables
